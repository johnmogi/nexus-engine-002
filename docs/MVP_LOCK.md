# MVP lock

This pass is the admin generator core for Nexus DM Poker Tool (`card-maze-core`).

In scope:

- Seeded cards, rooms, monsters, traps, loot, characters, NPC/clue prompts, maps, and dice
- A local admin UI
- Session log copy, JSON export, and clear
- Simple session stats
- Dungeo as the only live theme

Out of scope:

- A playable player game
- Combat screens
- Prophecy, Eclipse, hidden identities, and trading
- Lore editor, database, authentication, and multiplayer

The canonical repo is `nexus-engine-002`.
